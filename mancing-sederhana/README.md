# Mancing Sederhana

Game mancing HTML untuk keluarga — lempar umpan ke dasar sungai, tunggu ikan menyergap, tarik!

## Cara main

1. Buka `index.html` di browser (HP atau PC).
2. Tap **Mulai Mancing** → **Lempar umpan** (casting ke dasar).
3. Di dasar, geser **⬅️ ➡️** agar umpan dekat ikan.
4. Saat muncul **SERANG!**, tap **Tarik sekarang!** sebelum waktu habis.
5. **Angkat umpan** untuk menghentikan di dasar dan lempar lagi.

## File

- `index.html` — halaman game
- `style.css` — tampilan sungai & UI
- `game.js` — logika mancing
